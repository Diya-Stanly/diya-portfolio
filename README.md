## 🚀 Featured Projects

### 1. CodeSage AI — Python Code Quality Analyzer

A web-based code analysis tool built with Python and Flask that checks Python code for syntax errors and code-quality issues. It integrates Ruff for linting and automated fixes.

- **Technologies:** Python, Flask, Ruff, HTML, CSS, JavaScript, Pytest
- **Live Demo:** [CodeSage AI](https://codesageai-ckk0.onrender.com/)
- **Source Code:** [GitHub Repository](https://github.com/Diya-Stanly/CodeSageAI)

### 2. AlignIQ — Computer Vision-Based Wellness System

An ongoing project exploring computer vision techniques to monitor posture and screen-related working habits and provide wellness insights for computer users.

- **Technologies:** Python, OpenCV, MediaPipe
- **Status:** In development

### 3. WeatherWise — Real-Time Weather Dashboard

A responsive weather dashboard that integrates the Open-Meteo API to display current weather conditions and five-day forecasts.

- **Technologies:** HTML, CSS, JavaScript, Open-Meteo API
- **Live Demo:** [WeatherWise](https://diya-stanly.github.io/weatherwise/)

### 4. SkillMatch — Resume Analyzer

A browser-based tool that compares resume keywords with a job description, calculates a match percentage, and highlights matched and missing skills.

- **Technologies:** HTML, CSS, JavaScript
- **Live Demo:** [SkillMatch](https://diya-stanly.github.io/skillmatch/)

### 5. StudySync — Study Planner

A frontend web application designed to help students organize study-related tasks through an interactive and user-friendly interface.

- **Technologies:** HTML, CSS, JavaScript
- **Live Demo:** [StudySync](https://diya-stanly.github.io/studysync/)

### 6. VR Dictionary for Zoology and Botany

An educational virtual reality project designed to support interactive learning of zoological and botanical concepts.

- **Technologies:** Unity, C#, Unity XR
